An interactive educational web game designed to gamify the process of learning human anatomy. 

 🌐 Live Demo
Play the game here: https://ali-lab-dotcom.github.io/anatomy-battle/

🚀 Features
* **Multi-language Support:** Full localization in English, Kazakh, and Russian.
* **Progressive Difficulty:** Structured topics and difficulty tiers to match student knowledge.
* **Dynamic Gameplay:** Clean and interactive user interface built with optimized DOM manipulation.
 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Architecture:** Modular codebase with separated structure (HTML) and logic (JS).
* **Hosting:** GitHub Pages
